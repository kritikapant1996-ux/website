# SkillUp - Public Speaking Learning Platform

SkillUp is a modern, interactive platform designed to help users master the art of public speaking. Built with Next.js 14, Tailwind CSS, and Supabase, it offers structured courses, self-assessment tools, and a seamless learning experience.

## Features

-   **Interactive Courses**: Structured modules to guide you through public speaking techniques.
-   **Self-Assessment Quiz**: Evaluate your current skills and get personalized feedback.
-   **Modern Design**: Responsive and accessible UI with a premium aesthetic.
-   **User Authentication**: Secure login and registration flows.

## Tech Stack

-   **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
-   **Language**: TypeScript
-   **Backend/Auth**: [Supabase](https://supabase.com/)

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
